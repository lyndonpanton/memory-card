# Memory Card

## Description

A game where the player is shown multiple cards, each with a different image on
them. When they pick a card, the cards are redisplayed in a random order, and
the player should continue picking until they pick a card that they had
previously already picked. The player is given a score that increases everytime
they pick a card that they have not already picked.

### Features

- Cards are displayed in rows
- Player score increments every time an unpicked card is chosen
- Game over occurs when the player picks a card they have already picked
previously
- Game can be restarted
